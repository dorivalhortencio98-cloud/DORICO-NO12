# DORICO NO12 PRO

Aplicativo Streamlit de análise estatística de futebol.

## Publicação

1. Envie os arquivos desta pasta para a raiz de um repositório GitHub (sem compactar).
2. No Streamlit Community Cloud, selecione esse repositório e `app.py`.
3. Configure o segredo `FOOTBALL_DATA_TOKEN` nas configurações privadas do aplicativo.
4. Publique e teste o link fornecido pelo Streamlit.

**Atenção:** o arquivo `.gitignore` protege segredos locais; não publique tokens ou arquivos `.env`. O banner é ilustrativo, e a navegação real é feita pelas abas do aplicativo.

As probabilidades são estimativas experimentais e não garantem resultados. O modo ao vivo depende da cobertura da API.
